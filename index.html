01

The Problem

Textile retrieval can accidentally learn color instead of design.

The goal is to identify the visual design on a saree independently of the palette in which it is rendered.

SAME DESIGN
+ DIFFERENT COLORS
→ MATCH
DIFFERENT DESIGN
+ SAME COLORS
→ REJECT
